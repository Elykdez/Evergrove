# Evergrove 使用帮助

[English](help.en.md) | **简体中文**

Evergrove 是一个简洁的程序化树木生成器。它会在你设定的树冠形状内生长出一棵三维树木，并可导出到 Blender、游戏引擎或任何支持 glTF/OBJ 的工具。全部运算都在浏览器中完成；相同的参数和种子总会得到完全相同的树。

## 快速上手

无需安装即可试用：在支持 WebGPU 的浏览器（见下文）中打开在线版 <https://elykdez.github.io/Evergrove/>。如需在本地运行，需要 [Node.js](https://nodejs.org/) 18 或更高版本，以及支持 **WebGPU** 的浏览器：Chrome 或 Edge 113 及以上、Safari 26 及以上，或 Windows 上的 Firefox 141 及以上。浏览器不支持 WebGPU 时，应用会显示提示且不会启动。

```bash
npm install
npm run dev
```

然后打开终端中显示的地址（默认为 http://127.0.0.1:5173）。在 Windows 上也可以直接双击 `Run Evergrove.cmd`；在 macOS 或 Linux 上运行 `Run Evergrove.sh`。

## 界面说明

应用启动时，画面先显示合成波风格的网格世界：紫色晚霞下的青色网格，第一棵树以深色剪影出现；随后一道扫描光环从树干向外扩散，正常画面随之出现。此动画每次打开页面播放一次，不影响任何导出内容；勾选“场景 > 视图”中的 **复古风格** 可再次进入。加载新树（切换预设或种子）以及树林重新生长时也会播放同样的扫描，控制面板会同步切换为霓虹风格，树木和树林出现后再回到清爽的自然风格。

画面左上角的小计数器显示帧率（每秒帧数），可以看出预设、大片树林或镜头效果对 GPU 的负担。每一步（生长、树林、纹理、导出）的进度和耗时都会输出到浏览器的开发者控制台（F12）。

- **三维视图**：按住鼠标左键拖动可旋转视角，右键拖动可平移，滚轮缩放。
- **控制面板**（右侧）：所有内容都在这里。
  - **顶部**：语言选择，以及 **树木**（决定导出的树木形态）、**场景**（画面效果，不会导出）和 **导出**（下载与批量生成）三个标签页。每个标签页开头有一行说明它影响什么。标签页末尾的 GitHub 按钮会在新标签页中打开项目源代码。
  - **分组**：各标签页的设置按分组排列，点击分组标题可展开或收起，每个分组开头有一行提示。
  - **摘要与下载栏**（底部，所有标签页都有）：当前树木的预设和种子、关键数据，以及 **下载 GLB** 和 **OBJ** 按钮。
  - **折叠按钮**（标签页末尾的圆形按钮）：收起设置，屏幕上只留下树木，以及顶部、一行摘要和当前标签页的快捷操作：树木页为**随机种子**，场景页为**树林**、**调试器**和**后处理**开关，导出页为**下载 GLB**和**批量**（点击后展开面板并定位到批量生成）。收起时切换标签页会切换这些操作。点击摘要行或折叠按钮即可展开。面板默认收起；在手机上，面板位于屏幕底部。

摘要示例：**枝梢** 457、**三角面** 74,145、**耗时** 322 毫秒，下方一行为 `1,726 个节点 · 1 根主干 · 主干半径 0.25 米`：

| 项目 | 含义 |
| --- | --- |
| 枝梢 | 枝条末端，大部分树叶长在这里 |
| 三角面 | 导出网格的面数 |
| 耗时 | 生长并生成网格所用的时间 |
| 节点 | 枝干骨架中的点数 |
| 主干、主干半径 | 到达地面的主干数量，以及最粗主干的半径（米） |

## 常用流程

1. 点选一个接近目标树种的**预设**卡片。
2. 反复点击**随机种子**（骰子），直到整体形态满意。种子只改变细节，不改变树种。
3. 调整**树冠形状**来设定大小和轮廓，再调整**树叶**和**树皮**的外观。
4. 点击面板底部的**下载 GLB**（单个文件，含纹理）或 **OBJ**。
5. 想看这棵树在一群变体中的样子，开启**树林**（场景标签页）；需要一次下载大量变体时，在导出标签页使用**批量生成**（面板收起时，点击“下载 GLB”旁的**批量**按钮即可打开）。

拖动滑块时，树木会原地重新生长。

## 控制面板

| 标签页 | 内容 |
| --- | --- |
| 树木 | 预设卡片、种子及全部[参数](#参数详解) |
| 场景 | 视图、树林、天空、风、草地、镜头和调试器 |
| 导出 | 导出按钮与批量生成 |

摘要与下载栏位于每个标签页底部。

### 语言、预设、种子

- **语言**：English 或简体中文，在面板右上角选择。首次打开时跟随浏览器的首选语言，取其中第一个受支持的语言，都不支持时使用英文。手动选择的语言会被记住，此后优先于浏览器设置。也可以在地址后加 `?lang=zh-CN` 或 `?lang=en` 打开。
- **预设**：树木标签页顶部的图标卡片，是各树种的起点。选择预设会替换全部参数。

  | 预设 | 特点 |
  | --- | --- |
  | 橡树、枫树、杨树、金合欢 | 阔叶树，使用空间殖民算法生长 |
  | 柳树 | 空间殖民 + 强重力，枝条下垂 |
  | 苹果树 | 低矮圆润的果树，结红苹果 |
  | 针叶树 | 支撑扫描，锥形树冠内有一根中央主梢 |
  | 灌木 | 支撑扫描，无主干牵引，形成多根茎干 |

- **种子**与**随机种子**：输入种子，或点击骰子随机选取。相同的种子和参数总会得到相同的树。

### 视图（场景标签页）

这些选项只影响显示，不影响导出内容。

| 选项 | 显示内容 |
| --- | --- |
| 树叶、树皮、果实 | 树木的各个组成部分 |
| 树冠包络 | 树木生长所依据的蓝色线框 |
| 生长骨架 | 枝干图，从低到高由蓝变红 |
| 吸引点 / 枝梢 | 引导生长的采样点 |
| 自动旋转 | 视角缓慢旋转 |
| 复古风格 | 扫描回到启动时的网格世界，条纹状的合成波太阳位于真实太阳的方向（可在“天空”中调整）；取消勾选即扫描回正常画面 |

### 树林（场景标签页）

树林会在当前树木周围生成它的变体，便于把预设当作一片树林来看，而不只是一棵样本。树林中的树木依次使用后续种子（种子 + 1、+ 2……），与顺序批量生成相同，并带有少量参数变化；它们的位置也由种子决定：相同的种子和设置总会得到相同的树林。树林中的树木在复古加载画面下逐棵生长，最后一棵长成后正常画面扫描回来；修改参数、种子、预设或树林设置后也会这样重新生长（拖动滑块时在松开后进行）。视图中的树叶、树皮、果实开关同样作用于树林；调试器和调试视图只显示主树。

| 选项 | 效果 |
| --- | --- |
| 显示树林 | 开启或关闭树林（默认关闭，画面一开始只有一棵树；面板收起时场景页也有此开关） |
| 树木数量 | 主树周围的树木数量（1 到 16）。修改数量时，已有的树木位置不变 |
| 间距（米） | 任意两棵树主干之间的最小距离，包括主树 |
| 参数变化 | 树林中的树木与主树的差异：0 只改变种子。效果与批量生成的参数变化相同 |

摘要会在主树数据下方显示树林的树木数和三角面数，上方的数据仍只属于主树。每棵树的生长时间与主树相近，因此预设较复杂、树木较多时，树林需要几秒钟才能加载完成。树木在后台线程中生长，可同时生长多棵，因此期间画面和面板依然流畅；主树和批量生成也是如此。普通下载只导出主树；导出标签页的**下载树林 GLB** 会导出全部树木。

### 调试器（场景标签页）

叠加在树上的生长算法检查工具。它在 CPU 上测量真实几何（与生长采样相同的 `Crown.point`，以及经过重力、平滑和简化后的最终骨架），所以报告的就是算法实际生成的结果。勾选 **调试生长算法** 即可开启（也可在收起的场景页点击**调试器**按钮）；其余选项只在开启时生效，关闭时显示为灰色；开启期间风会停下，标记始终贴在枝干上。面板底部的摘要会多出一行检查结果：分叉点数量（及其中三叉及以上的数量）、超出树冠的枝端数量与最大超出比例，以及未到达的树冠采样点。

| 选项 | 显示内容 |
| --- | --- |
| 隐藏树叶和果实 | 调试时移开树叶和果实（关闭调试器后恢复“视图”中的设置） |
| 树冠表面、表面不透明度 | 以半透明实体显示树冠包络，按 1/f 噪声着色：凸起处为暖色，凹陷处为冷色，平坦处为绿色。灰色表示低于枝梢截断的方向，那里不放置枝梢或吸引点 |
| 枝端 | 最终骨架的每个末端，按沿树冠中心射线的深度着色：在表面上为绿色，越深入内部越偏蓝，超出表面 2% 以上为红色。噪声很强的圆锥表面自身折叠时，以最外层为准 |
| 分叉点 | 枝干交汇处：黄色为普通二分叉，粉色为三条及以上同时交汇（例如扫描算法在同一层合并多根枝条） |
| 树干基部 | 每根树干与地面相接处的白色圆环；多于一个即为多干树 |
| 未到达的采样点 | 空间殖民从未消耗的吸引点（树冠中的空缺），或低于第一层的扫描枝梢 |
| 标记穿透树皮显示 | 标记绘制在最上层，粗枝内部的分叉点也能看到 |

如何解读：枝端超出树冠通常来自 **重力**，它把向上生长的枝条转向地面，使枝端甩出树冠侧面；也可能是空间殖民的 **步长** 大于树冠的凹陷。大量吸引点未到达，说明 **影响半径** 太小或 **最大迭代次数** 已用完。

### 天空、草地、风和镜头（场景标签页）

场景标签页中的设置只改变画面效果，不会改变树木、参数或导出内容（树林只会通过**下载树林 GLB** 导出）。**重置场景** 可将树林、天空、草地、风和镜头恢复为默认值。

**天空**

| 设置 | 效果 |
| --- | --- |
| 云量 | 0 为晴空，1 为阴天 |
| 云速 | 云飘动的速度，0 为静止 |
| 太阳高度角、太阳方位角 | 太阳的位置（度），光照和阴影随之变化 |
| 天空颜色、地平线颜色 | 头顶和地平线处的颜色，远处的雾气使用地平线颜色 |

**草地**

草地在地面上散布实例化的草叶，越靠近主干越密，向远处逐渐稀疏。草叶与树木受同一阵风吹动，形成在草地上滚动的波浪。草地只用于显示：不会被导出，也不计入三角面预算。

| 选项 | 作用 |
| --- | --- |
| 显示草地 | 开启或关闭草地 |
| 草叶数量 | 草叶数量（每片 5 个三角面，一次绘制完成） |
| 高度（米）、草叶宽度（米） | 草叶的平均尺寸，每片草叶会在此基础上变化 |
| 根部颜色、叶尖颜色 | 草叶根部和叶尖的颜色 |
| 风力响应 | 草地对风的反应强度 |

**镜头**

默认效果是轻度的电影感后期。任一效果设为 0 即可关闭，取消勾选 **后处理** 可查看原始渲染。

| 设置 | 效果 |
| --- | --- |
| 景深 | 模糊旋转中心前后的景物，旋转中心保持清晰 |
| 泛光 | 太阳和强光照表面周围的柔和光晕 |
| 暗角 | 压暗画面四角 |
| 胶片颗粒 | 细微的动态噪点 |
| 曝光 | 整体亮度 |

**风**

风在 GPU 上为树木添加动画：枝条摆动，越往上摆幅越大；树叶绕叶柄抖动。风只影响显示，不会改变导出内容。

| 选项 | 作用 |
| --- | --- |
| 开启动画 | 开启或关闭风 |
| 强度 | 树冠摆动幅度，按树高自动缩放 |
| 速度 | 阵风变化的快慢 |
| 方向（度） | 风吹向的方向，绕竖直轴计算 |
| 树叶抖动 | 每片叶子的摆动幅度 |


### 导出（导出标签页）

| 按钮 | 文件 |
| --- | --- |
| 下载 GLB（含纹理） | `tree-<预设>-<种子>.glb`，包含树皮、树叶、果实（如有）及两张内嵌纹理 |
| 下载 OBJ（仅几何） | `tree-<预设>-<种子>.obj`，仅几何体 |
| 下载树林 GLB（全部树木） | `grove-<预设>-<种子>-<n>x.glb`：主树与树林中的所有树木合为一个文件，位置与画面一致，纹理只内嵌一次 |
| 下载树叶纹理 / 树皮纹理 | PNG 纹理，配合 OBJ 使用 |

文件名始终使用英文预设名，例如 `tree-oak-7.glb`。

## 参数详解

长度单位均为米。以下小标题与树木标签页中的分组一一对应，依次为：树冠形状、枝干、树叶、果实、树皮、生长方法、轮廓噪声、细节与平滑。

### 生长方法

- **算法**：
  - **空间殖民**：从主干向上生长，朝树冠内散布的吸引点延伸。大多数阔叶预设使用此算法。
  - **支撑扫描（逆向）**：从树冠表面的枝梢向下生长，逐层合并成主干。针叶树和灌木使用此算法。

只显示当前算法的设置：**空间殖民**一组，或**枝梢（扫描）**与**支撑扫描**两组。“最低方向”两种算法都会使用，始终显示。

### 树冠形状

树木要填充的外形包络。

| 参数 | 作用 |
| --- | --- |
| 形状 | 球形、锥形或伞形 |
| 半径（米） | 树冠整体大小 |
| 中心高度（米） | 树冠中心离地高度 |
| 垂直拉伸 | 大于 1 时高而窄，小于 1 时扁而宽 |
| X / Z 偏移（倾斜） | 横向移动树冠，使主干倾斜 |
| 锥度（正值底部宽） | 仅球形。正值使顶部收窄、底部变宽，如宽端朝下的蛋形；负值使顶部变宽。0 为普通球形 |
| 方度（2 为圆） | 仅球形。2 为圆；越大顶部、底部和侧面越平，接近圆角方块；越小则在顶部、底部和赤道处收成尖角（1 时为菱形） |
| 底面宽度 | 仅伞形。底面宽度占伞顶宽度的比例；1 与顶部同宽，数值小时底面细如伞柄 |
| 伞缘高度 | 仅伞形。底面过渡到伞冠的位置，从 -0.9（低，伞冠深）到 0.9（高，伞冠浅） |
| 伞缘柔和度 | 仅伞形。过渡的缓急：数值小为锐利的伞缘，数值大为圆滑的穹顶 |

球形和伞形的滑块只在对应形状下显示。默认值与原来的形状完全一致，因此已有的种子生成的树不变。修改任何参数都会原地重新生长：拖动滑块时每秒最多重新生长十次，多次生长在后台重叠进行，最终总以松开时的值为准。只有生成新树时（切换预设、点击 **随机种子** 或修改 **种子**）才会播放复古扫描过渡。

### 轮廓噪声

让树冠轮廓像真实树冠一样不规则。分组开头是噪声频谱图：每条竖线代表一个波，横向位置为频率，高度为振幅。

| 参数 | 作用 |
| --- | --- |
| 强度 | 轮廓凹凸的幅度（0 为光滑形状） |
| 斜率 β | 越大越呈现大而平滑的起伏，越小越粗糙细碎 |
| 模态数 | 叠加的波数，越多轮廓越丰富 |
| 最低 / 最高频率 | 凹凸尺寸范围，从大块起伏到细小细节 |

### 空间殖民（生长方法）

| 参数 | 作用 |
| --- | --- |
| 吸引点数量 | 树冠内散布的点数。越多分枝越密（也越慢） |
| 影响半径（米） | 枝条能感知吸引点的距离。越大枝条越长越直 |
| 消除距离（米） | 枝条靠近到此距离时吸引点被消耗。越小树冠填充越细密 |
| 步长（米） | 每步生长长度。越小越平滑但越慢 |
| 向性（+向上 / -下垂） | 恒定方向偏置：正值向上生长，负值下垂 |
| 最大迭代次数 | 生长步数上限。若树冠未填满就停止，请调高 |

### 枝梢（扫描，生长方法）

| 参数 | 作用 |
| --- | --- |
| 数量 | 树冠表面的枝梢数量 |
| 最低方向 | 树冠向下多远仍分布枝梢或吸引点（-1 为整个树冠，0 为上半部分）。两种算法都会使用 |
| 内缩深度 | 枝梢可以位于表面以内多深 |
| 抖动 | 枝梢位置的随机偏移 |

### 枝干

| 参数 | 作用 |
| --- | --- |
| 扭曲度 | 每步的随机摆动。0 为笔直，1 为扭曲 |
| 梢端半径（米） | 最细枝条的粗细 |
| 管道指数 | 枝条汇合处变粗的速度。2 保持截面积不变（达·芬奇法则），真实树木约在 2 到 3 之间。越小主干越粗 |
| 每米增粗 | 每米枝长额外增加的半径，使长枝逐渐变细 |
| 重力（下垂） | 枝条因自重弯曲，越细弯得越多；约为 1 时呈垂柳状 |

### 支撑扫描（生长方法）

| 参数 | 作用 |
| --- | --- |
| 层高（米） | 向下扫描的每层高度 |
| 分枝角度 | 每步偏离竖直方向的最大角度（度） |
| 合并半径（米） | 相距多远的枝条仍会相互靠拢 |
| 主干牵引 | 树冠以下向单一主干聚拢的力度。0 会形成多茎灌木 |
| 树冠牵引（主梢） | 树冠内部向中轴聚拢的力度。较高时形成针叶树的单一主梢 |

### 细节与平滑

- **限制三角面数**与**三角面预算**：整棵树最多可用的三角面数，范围 1,000 到 10,000；不勾选时不限，拖动滑块会自动勾选。超出时，应用会分阶段恰好降低所需的细节：先减少树皮的边数和环数，再简化枝条路径，预算极小时还会从树皮上剪去最细的小枝和根部隆起。树叶始终生长在完整的骨架上，所以树冠形态不变，只是叶片更少、更大（最多 3 倍）；果实先减少面数，再减少个数。削减树皮时，预算的 40% 会留给树叶和果实。降低细节后摘要会显示“已按……面预算精简”；若最低细节仍超出，则显示“最低细节下仍超出……面预算”。批量生成时，预算对每棵树单独生效。

| 参数 | 作用 |
| --- | --- |
| 迭代次数、强度 | 枝条路径的平滑程度 |
| 简化角度 | 弯折小于此角度的近直线段会被合并，可减少三角面 |

## 批量生成

**批量生成**文件夹会基于当前参数生成多个变体，并打包成一个 ZIP 下载。

| 设置 | 作用 |
| --- | --- |
| 树木数量 | 生成数量（1 到 500） |
| 种子序列 | **连续**：从当前种子开始依次加 1，第一棵就是屏幕上的树。**分散**：种子分布在整个范围内 |
| 参数变化 | 0 时只改变种子。数值越大，树冠大小、高度、拉伸、轮廓、倾斜、向性、扭曲度、叶片尺寸、下垂、色相和果实尺寸的变化越大，且都限制在各滑块范围内 |
| 结果树比例 | 批次中结果树木所占比例（默认 0.1，即 20 棵中 2 棵）。恰好按此比例根据种子选出结果的树，其余不结果。果实外观取自**果实**设置，即使“结果”未勾选也会使用 |
| 包含 GLB / 包含 OBJ | ZIP 中包含的格式，至少选择一种 |

点击**生成并下载 ZIP**。运行时按钮会显示进度，例如 `取消（12 / 50）`，再次点击即可停止；取消后不会下载任何文件。

ZIP 文件名形如 `trees-oak-50x-seed7.zip`，其中包含：

- 按顺序编号的 `001-tree-oak-7.glb`、`002-tree-oak-8.glb` ……
- 若包含 OBJ，还有对应的 `.obj` 文件和 `textures/` 文件夹
- `manifest.json`：记录每棵树的种子、统计数据（含果实数量）和全部参数

相同的设置总会生成相同的批次。若想在应用中重建其中某一棵树：选择相同的预设，填入清单中的种子；如果参数变化大于 0，再按清单填入该树的参数值。

GLB 大约只有 OBJ 的四分之一大小，大批量时建议只选 GLB。

## 使用导出文件

- **单位与坐标轴**：米，Y 轴向上，主干底部位于原点。
- **GLB**：包含 `Bark`（树皮）和 `Leaves`（树叶）网格，结果时另有 `Fruit`（果实）网格。树叶材质为双面、Alpha 遮罩（镂空），并使用顶点颜色，因此每片叶子颜色略有不同；果实同样使用顶点颜色。Blender 中使用 *文件 > 导入 > glTF 2.0*；Unity、Unreal、Godot 可直接导入。
- **树林 GLB**：一个 `Grove` 节点下，每棵树对应一个 `Tree-<种子>` 节点，各自带有平移和绕 Y 轴的旋转，网格与单棵树的 GLB 相同（`Bark`、`Leaves`、`Fruit`）。主树位于原点。
- **OBJ**：只包含顶点、法线和 UV，不含颜色。需要自行指定树皮和树叶 PNG，将树叶材质设为 Alpha 裁剪（镂空）和双面，并为果实指定纯色材质。

## 工作原理

1. **树冠表面**：基础形状（球形、锥形或伞形）在每个方向上的半径来自轮廓函数（球形的锥度和超椭圆方度，伞形的底面宽度、伞缘高度和柔和度），再由频谱噪声扰动。噪声由振幅 ~ f^-β 的随机平面波叠加而成，相当于对 1/f^β 频谱做逆 FFT，但直接在球面上求值，因此没有接缝。噪声方差经过归一化，所以“强度”在任何斜率下含义一致。“轮廓噪声”分组会绘制该频谱。
2. **生长**，二选一：
   - **空间殖民**（Runions、Lane、Prusinkiewicz，2007）：吸引点填满树冠。每个吸引点牵引影响半径内最近的枝干节点，被牵引的节点朝吸引点生长一步，枝条到达的吸引点会被移除。对吸引点的竞争使枝条自然分开并形成层级。
   - **支撑扫描**：把 3D 打印的树状支撑算法倒过来运行。树冠表面的枝梢逐层下降，在分枝角度限制内向邻近枝条靠拢并合并，向中轴的牵引把它们汇聚成主干。
3. **半径**遵循管道模型：父枝 r^e = 各子枝 r^e 之和。
4. **重力**：刚度与半径的三次方成正比，因此粗枝保持挺直而细枝下垂。弯曲沿枝条向外传递，这正是垂柳下垂的原因。
5. **整理**：平滑处理，然后合并近乎笔直的线段。
6. **网格化**：树皮管道沿每条枝链生成并重采样为平滑曲线，底部生成板根。树叶是位于每个枝梢及细枝上的折叠面片，逐叶着色。
7. **果实**：每个枝梢按“密度”随机决定是否结果；果实通过细果柄挂在枝梢下方，若会触地则跳过。整棵树的果实颜色由基础颜色加上一个由种子决定的色相、饱和度和亮度偏移得到，偏移幅度不超过“颜色变化”。果实使用独立的随机序列，因此开启果实不会改变枝干和树叶。
8. **三角面预算**：一个细节系数同时决定树皮的边数和环数、额外的路径简化、树皮保留的小枝末梢数量、叶片数量和果实面数。剪枝会去掉所有比某个阈值半径更细的枝条，阈值取能使末梢足够少的最小值；被剪光的枝条末端收成尖头。先通过简短搜索找到树皮能满足预算的最大系数，同时为树叶预留一部分预算，再让树叶和果实填满剩下的余量，结果通常与预算相差不到几个百分点。
9. **纹理**在 GPU 上以着色器逐像素计算，再读回一次以便嵌入导出文件。树叶纹理为灰度加镂空，一张纹理即可适配任意颜色；树皮纹理可无缝平铺。
10. **渲染**使用 WebGPU。风、树冠包络视图和骨架颜色都在着色器中计算。树木生长和网格生成仍在 CPU 上进行，这样每棵树在任何 GPU 上都能由种子精确重现，导出的也正是这些数据。

## 技巧与常见问题

- **重新生成太慢**：降低“吸引点数量”“数量”或“最大迭代次数”，或增大“步长”。树叶开销很小，主要耗时在枝干。
- **三角面太多**：勾选“限制三角面数”。若要手动调整，可降低“每梢叶数”和“沿细枝每米叶数”，减少树皮“分段数”和“曲线细分”，增大“简化角度”，或降低果实“面数”。
- **树没有填满树冠**：增大“最大迭代次数”或“影响半径”。
- **主干过细或过粗**：调整“管道指数”（越小越粗）或“每米增粗”。
- **枝条下垂过多或过少**：调整“重力（下垂）”和“向性”。
- **启动时语言不对**：在“语言”中切换，或用 `?lang=zh-CN` 打开。
- **大批量占用内存过多**：只选 GLB，或分成几个较小的批次。
